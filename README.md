1. Общая идея аддона

Аддон автоматизирует типичный пайплайн:

у тебя есть коллекции (часто вложенные)
внутри лежат меши
меши бывают:
high poly (_hp)
low poly (_lp)
или вообще один объект без пары

Аддон делает:

авто-назначение HP/LP
авто-дублирование если пары нет
синхронное переименование объектов и mesh data
управление видимостью
выделение HP/LP внутри выбранной коллекции
экспорт LP в .glb
2. Структура сцен

Ожидаемая структура:

ROOT_COLLECTION
    Weapon_A
        mesh1
        mesh2

    Weapon_B
        mesh1

    Weapon_C
        mesh1
        mesh2
3. обработка коллекций

Аддон делает:

берёт активную коллекцию (root)
рекурсивно проходит все вложенные коллекции

То есть:
обрабатываются дочерние коллекции
4. Логика HP / LP назначения
CASE A — 2 объекта в коллекции

Если в коллекции ровно 2 mesh объекта:

сравнивается количество полигонов
более плотный → _hp
менее плотный → _lp

Пример:

Cube_A (10k tris)
Cube_B (2k tris)

→

CollectionName_hp
CollectionName_lp
CASE B — 1 объект в коллекции

Если только 1 mesh:

он считается _lp
создаётся копия
копия становится _hp

Пример:

Door_mesh

→

Door_lp (оригинал)
Door_hp (копия)
CASE C — уже обработанная коллекция

Если в коллекции уже есть:

_hp
_lp

→ коллекция полностью пропускается

Это защита от повторного запуска.

CASE D — нестандарт (0 / >2 мешей)
коллекция пропускается
ничего не меняется
5. Переименование

Аддон делает двойное переименование:

Object name:
Door_hp
Door_lp
Mesh data:
тоже становится Door_hp / Door_lp

Это важно для:

baking
export consistency
Substance Painter matching
6. Выделение HP / LP

Работает ТОЛЬКО внутри активной root коллекции.

Select HP:
выбирает все объекты с _hp
только внутри выбранной коллекции
игнорирует всю сцену
Select LP:
то же самое для _lp
7. Скрытие / показ

Работает так же как select:

Hide HP:
скрывает только _hp внутри root
Show HP:
показывает только _hp внутри root
Hide LP / Show LP:
аналогично

Важно:

не трогает другие коллекции
не влияет на сцену целиком
8. Экспорт LP в GLB

Это отдельный pipeline:

Что экспортируется:
только _lp объекты
только внутри выбранной root collection
рекурсивно по всем вложенным коллекциям
Как формируется имя файла:
Door_lp → Door.glb
_lp удаляется
имя берётся из object name
Что делает экспорт:

Для каждого _lp:

выделяет объект
делает его active
вызывает glTF exporter
Результат:
Door.glb
Crate.glb
Weapon.glb
9. Preset система

Аддон:

ищет glTF exporter presets Blender
показывает их в UI
позволяет выбрать preset

Preset влияет на:

compression
normals
materials
animations (если включены)
